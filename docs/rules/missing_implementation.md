Flags functions that are declared in a header file but have no matching
definition in any `.c` file in the project.

## Why?

- **Linker errors**: a missing implementation causes `undefined reference`
  errors when the function is actually called, but only at link time — catching
  it earlier saves debugging effort
- **Stale headers**: after refactoring, declarations may be left behind in
  headers when the implementation is removed or renamed
- **API promises**: a declaration in a public header is a promise to consumers;
  a missing body means the library cannot deliver on that promise

## What is NOT flagged

- **Static declarations** — these are file-local and handled separately
- **`_quark` functions** — typically generated by GLib macros
  (`G_DEFINE_QUARK`) and may not have a visible definition in the source
- **`_get_type` functions** — generated by `G_DEFINE_TYPE` and similar macros,
  recognized automatically

## Examples

**Flagged** (declared but never defined):
```c
/* mylib.h */
void my_lib_do_work (void);

/* No my_lib_do_work() definition exists in any .c file */
```

**Not flagged** (declaration has a matching definition):
```c
/* mylib.h */
void my_lib_do_work (void);

/* mylib.c */
void
my_lib_do_work (void)
{
  /* ... */
}
```
